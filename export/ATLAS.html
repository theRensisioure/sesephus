→ Daily operate spine launchers

Testers need only steps 1–2. The Fleet (3) is optional dashboard glass. Click a station to highlight its module on the map.

  1. Install once required
    install.bat
    Creates venv, installs requirements-dev + Whisper, writes sesefus.config.json, rebuilds tools/atlas/sesefus-atlas.html, arms .githooks. Needs Python 3.10+ on PATH.
  2. Journal loop ships
    voice.bat → tools/voice.py
    Push-to-talk (Enter / Enter). Long speech → Whisper → aurgio/transcript/ → ETDI score. Short phrases ≤5 words: status · review last · score · dashboard · goodbye. No Zig required.
  3. Bring up the Fleet
    fleet.bat → tools/fleet.ps1
    Supervises three runtimes: Engine (Zig host, TCP 5000 + HTTP 3000), Bridge (FastAPI 3001), Glass (Vite 5173). Open Glass at http://127.0.0.1:5173 — Bridge root is API-only (404). Flags: -ProbeOnly · -Reap · -Watch.
  4. Zig engine REPL
    ssfs.bat → zig build → zig-out/bin/sesefus.exe
    Space-separated commands. WIRED today: status · alarm * · group * · lead qualify · vault ingest-archive · dialogue start|review · backup · exit. Host flags: --read-vault · --extract. Global: --production · --dry-run.
  5. Recovery moves
    fleet.ps1 -Reap · ports · guards
    Port clash on 5000/3000/3001/5173 → fleet.ps1 -Reap. Orphan processes → -ProbeOnly first. Vault/secrets almost committed → .githooks via install.bat / tools/install_guards.sh. Rebuild machine atlas: python tools/atlas/build.py.
Do not build workflows on stubs — journal, rhythm, stoic, lead mine|feed, most of vault only print canned lines. Real journal = voice.bat. Real scheduler = alarm.
