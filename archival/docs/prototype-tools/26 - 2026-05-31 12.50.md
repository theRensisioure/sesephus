## Updated Design Document  
**Arcadium & Circadia – Audio Journal v1 (Local‑Only, Zero‑Trust)**  

&gt; **Goal:** Build a desktop‑first audio journaling system that *never* relies on external cloud services. All inference, storage and communication stay within the local hardware topology.  
&gt; **Constraints:**  
&gt; 1️⃣ No Cloud Reliance – everything runs locally.  
&gt; 2️⃣ Interface‑First – define all structs/enums/proto interfaces before coding.  
&gt; 3️⃣ Decoupled Logic – modules can’t access each other’s data stores directly; they communicate via NATS or gRPC over mTLS.  
&gt; 4️⃣ Zero‑Trust Networking – local network is secured with mutual TLS certificates.

---

### 1. High‑Level Architecture

```
┌─────────────────────┐      ┌──────────────────────────┐
│   NODE_01 (Backend) │&lt;--NATS/gRPC--&gt;│   NODE_02 (Frontend)  │
│   • FastAPI/Whisper  │     │   • Tauri (Rust + UI)  │
│   • PostgreSQL       │     │   • Audio Player       │
│   • pgvector         │     │   • Search UI           │
└─────────────────────┘      └──────────────────────────┘
```

- **NODE_01** runs the heavy ML inference (Whisper transcription, embeddings) and database operations.  
- **NODE_02** is the native desktop app that users interact with – it sends audio files to NODE_01 via NATS/gRPC and receives results back.

All inter‑node traffic is encrypted with mTLS; no direct DB connections from the frontend.

### 2. Interface‑First Definitions

#### 2.1 Protobuf (gRPC) for Node Communication  
```proto
syntax = "proto3";

package arcadium;

// Upload request – send raw audio file bytes.
message AudioUploadRequest {
  string filename   = 1;          // original name
  bytes content     = 2;          // raw audio data
}

// Response after processing
message AudioProcessingResponse {
  uuid entry_id        = 1;
  string transcript    = 2;
  repeated ChunkInfo chunks = 3;
}

message ChunkInfo {
  int32 index           = 1;
  float start_seconds   = 2;
  float end_seconds     = 3;
  string content       = 4;
  bytes embedding      = 5; // raw vector bytes (384 floats)
}

// Search request
message SearchRequest {
  string query            = 1;
  int32 limit              = 2;
}

message SearchResult {
  uuid entry_id          = 1;
  string snippet         = 2;
}
```

### 3. Zero‑Trust Networking (mTLS)

1. **Generate certificates** (self‑signed or via local CA) for each node.  
   ```bash
   openssl req -newkey rsa:2048 -nodes -x509 -days 365 \
     -subj "/CN=arcadium-node01" -out node01.crt -keyout node01.key
   ```
2. **Configure gRPC** to use `tls` with the certificates.  
3. **NATS** can also be configured with TLS (`nats-server --tls`).  
4. **Firewall rules**: restrict inbound/outbound traffic to the local network only.

---

### 4. Decoupled Logic

- **Backend (Node_01)** exposes a gRPC/NATS API for all operations.  
- **Frontend (Node_02)** never queries PostgreSQL directly; it only calls the backend API.  
- **Database** remains local, but its access is mediated by Node_01’s service layer.

---

### 5. Data Flow Overview

1. **User uploads audio** → Tauri UI sends `AudioUploadRequest` to Node_01.  
2. **Node_01**:  
   - Stores raw file in `/data/audio/`.  
   - Runs Whisper transcription → timestamps.  
   - Splits transcript into chunks (e.g., 500 chars with overlap).  
   - Generates embeddings using `all-MiniLM-L6-v2`.  
   - Inserts entries, transcripts, chunks, tags into PostgreSQL.  
3. **Node_01** sends `AudioProcessingResponse` back to Node_02.  
4. **Frontend** displays transcript, audio player, search UI.  
5. **Search**: User enters query → frontend sends `SearchRequest`.  
   - Backend performs vector similarity lookup in PostgreSQL (pgvector).  
   - Returns `SearchResult`.

### 1. Database Schema (PostgreSQL + pgvector)
We will use a relational schema to track audio files, transcripts, and their semantic chunks.

```sql
-- Extensions
CREATE EXTENSION IF NOT EXISTS vector;

-- Audio Entries
CREATE TABLE audio_entries (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    file_path TEXT NOT NULL,
    original_filename TEXT,
    duration_seconds FLOAT,
    mime_type TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Transcripts
CREATE TABLE transcripts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    audio_entry_id UUID REFERENCES audio_entries(id) ON DELETE CASCADE,
    full_text TEXT,
    model_name TEXT, -- e.g. "whisper-large-v3-turbo"
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Transcript Chunks (for semantic search)
CREATE TABLE transcript_chunks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    transcript_id UUID REFERENCES transcripts(id) ON DELETE CASCADE,
    chunk_index INT,
    start_time FLOAT,
    end_time FLOAT,
    content TEXT,
    embedding vector(384) -- Dimension depends on the model (e.g. all-MiniLM-L6-v2)
);

-- Tags
CREATE TABLE tags (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name TEXT UNIQUE NOT NULL
);

-- Entry-Tag Mapping
CREATE TABLE audio_entry_tags (
    audio_entry_id UUID REFERENCES audio_entries(id) ON DELETE CASCADE,
    tag_id UUID REFERENCES tags(id) ON DELETE CASCADE,
    PRIMARY KEY (audio_entry_id, tag_id)
);
```
